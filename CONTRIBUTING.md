# Contributing to Hijama Exorcist

1. Clone the repo

```sh
git clone git@github.com:hijamaexorcist/sanitypress.git
```

2. Create a branch

```sh
git checkout -b feature-or-bugfix-name
```

3. Make changes that follow the existing clinic schema and module conventions.

4. Commit with a clear message, then open a pull request against `main`.
